# Amendment 1 (2026-11-08 06:30Z): worker argument-format bug fix. DESIGN.md unchanged (sha256 6db864ab...).

Written before any clip affected by it was rendered and before any scoring.

**Failure.** Worker w3 (i-02c1d231aa6c1ba52) exited rc=1 at 06:27Z on clip f018_test_healthy_ball_crossing
(Blender: `argument --interleaf: expected one argument`).

**Root cause (deterministic, not transient).** `worker.py` passed each jitter value as a separate token,
`--interleaf -6.968540769014542e-05`. Python argparse only accepts a separate token starting with "-" as a value
if it matches its negative-number pattern, which excludes scientific notation. So any clip whose sampled jitter
value is NEGATIVE and below 1e-4 in magnitude fails at scene generation. It is not specific to a scenario.
In the frozen job list (`jobs/all_clips.json`) 4 values print in scientific notation; 3 are negative:
f018_test_healthy_ball_crossing (interleaf, w3), f020_test_healthy_clean (interleaf, w3),
f023_test_anomaly_door_desync (start_offset, w1). f015_test_healthy_balloon_partial (interleaf +1.9e-05, w2) is
positive and parses correctly.

**Fix.** `worker.py` now passes `--key=value` (e.g. `--interleaf=-6.968540769014542e-05`), which argparse parses
for every value. Values, clip specs, seeds and the job list are unchanged; all other code unchanged.

**Effect on already-rendered clips: none.** A clip either failed at scene generation (no output, no DONE marker,
nothing uploaded) or parsed every argument exactly as before; for values that parsed, `--k v` and `--k=v`
give identical floats. The worker crashes on the first failing clip, so the only consequence is clips not yet
produced.

**Re-run.** One extra g6.xlarge (w3r, i-076042a7d83acbd43, wall-clock cap 1 h) runs the 13 clips w3 did not
produce plus the 6 clips of w1 from f023_test_anomaly_door_desync onward (w1 will stop there for the same reason).
The worker skips any clip whose DONE marker already exists, so nothing is rendered twice. Scoring waits until all
302 planned clips exist (DESIGN missing-clip rule).
